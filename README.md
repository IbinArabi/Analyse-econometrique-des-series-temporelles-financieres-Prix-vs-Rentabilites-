# Projet d'Économétrie des Séries Temporelles

## 📌 Description
Ce projet analyse les propriétés statistiques des séries temporelles financières (données réelles) et les compare à des modèles théoriques simulés (processus ARMA). L'étude porte sur 10 actifs (indices, actions, devises, cryptomonnaies) sur la période 2020-2025.

## 📁 Contenu du dépôt
*   **`Source.R`** : Le script R complet. Il contient le téléchargement des données, les transformations, les tests de stationnarité, les graphiques et les simulations.
*   **`Rapport.pdf`** : Le rapport détaillé contenant l'ensemble des résultats, graphiques et interprétations économétriques.

## 🛠️ Prérequis et Exécution
*   **Logiciel :** R et RStudio
*   **Packages :** `quantmod`, `xts`, `PerformanceAnalytics`, `tseries`, `forecast`
*   **Pour exécuter :** Ouvrir le fichier `CODE R.R` dans RStudio et lancer le script. Les données financières seront automatiquement téléchargées depuis Yahoo Finance.
